instrucciones : 
se debe de abrir una terminal en visual y se debe de ejecutar el comando (gradle run --no-configuration-cache)

ejemplo: 
PS C:\Users\carol\Desktop\COMPUTACION INTERNET\proyectoChatGrupal> gradle run --no-configuration-cache

se debe de abrir varias terminales para tener varios clientes

cuando se esta creando grupos se debe de seleccionar quienes van a estar en el grupo y se crea

a la hora de hacer un audio debes de elegir a otro usuario y para escuchar el audio debes de ir a la ventana de ese usuario

a la hora de hacer un mensaje de texto debes de elegir a otro usuario y para ver el mensaje debes de ir a la ventana de ese usuario

para hacer una llamada minimo deben de haber dos usuarios, primero en la seleccion de puertos siempre dar aceptar en localHost
